PRO TRANS Logistics — DESIGN.md

1. Purpose

This document is the single source of truth for the visual design and UI/UX direction of the PRO TRANS Logistics LLP website.

The website is a premium, modern, corporate logistics portfolio. It is an informational company-profile website, not a logistics dashboard, booking platform, e-commerce system, or customer portal.

The implementation must communicate:

reliability

operational precision

speed

safety

transparency

fleet capability

FMCG expertise

professional credibility

South Indian and Pan-India connectivity

The design must feel custom-built and high-end rather than template-driven.

4. Brand Positioning

The visual language should support the message:

Speed. Safety. Reliability.

The supplied project material positions PRO TRANS around FMCG logistics, retail distribution, warehouse dispatch, last-mile delivery, fleet tracking, operational support, and reliable on-time delivery.

The website should therefore visually emphasize movement, route intelligence, fleet scale, precision, and dependable execution.

24. Motion System

Animation should reinforce the idea of movement and operational precision.

Principles

fast enough to feel responsive

slow enough to feel premium

never block interaction

respect reduced-motion preferences

avoid animation on every element

Recommended Durations

micro interaction: 120–180ms

hover: 180–250ms

component transition: 250–400ms

section reveal: 500–800ms

large image transition: 600–1000ms

Use easing similar to:

cubic-bezier(0.22, 1, 0.36, 1)

Scroll Reveals

Recommended:

opacity 0 → 1

translateY 20–32px → 0

subtle scale for imagery only

Avoid:

large bouncing entrances

spinning content

excessive parallax

long delays

Requirements:

44. Implementation Rules for AI Coding Agents

Before modifying a UI:

Inspect existing components.

Maintain the established visual language.

Do not introduce a new component style without a reason.

Keep responsive behavior consistent.

Respect accessibility requirements.

Respect reduced-motion preferences.

Do not invent business claims.

Do not introduce out-of-scope functionality.

When adding a new component, evaluate whether it should become a reusable pattern.

When changing an existing component, check all pages that use it.

47. Final Design Standard

The finished website should feel like a premium logistics company built by a specialist digital studio, not a template customized for a logistics company.

The visual system should communicate:

Precision + Movement + Reliability + Technology + Trust

Every design decision should answer at least one of these questions:

Does this make the company look more credible?

Does this improve clarity?

Does this strengthen the logistics story?

Does this make the experience easier to navigate?

Does this create useful visual hierarchy?

Does this improve perceived quality without adding unnecessary complexity?

If the answer is no, remove it.
